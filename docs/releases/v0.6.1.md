# recuerd0 v0.6.1

_Unreleased_

## Import confirmation and next actions

- **`import commit` now commits by default.** Interactive runs validate the reviewed plan,
  show its create/version counts and target workspace, and ask once before writing.
  Non-interactive callers must pass `--yes`; a decline or a plan with no writes exits zero
  without claiming a write.
- **Workspace naming is best-effort.** A failed workspace lookup no longer blocks an
  otherwise valid import. Commit continues with the workspace id and lets the writes return
  the authoritative authorization or validation error.
- **Guidance is part of the envelope.** Propose and commit retain their existing structured
  `data` while adding summaries, locations where available, and breadcrumbs for reviewing
  the plan, loading workspace context, and running the after-import pass.

## Skill installation guidance

`skills install` now reports the target directory in both its JSON envelope and a TTY-only
human block. It explains that Claude Code loads the installed skill automatically and that
other agents need `SKILL.md` added to their instructions.

## Shared conventions

The bundled CLI skill and the public MCP skill now use the same operations-based conventions
reference. Each interface keeps only its own commands or tools, while boot, retrieval,
writing, decisions, map maintenance, hubs, import organization, governance, and session
capture stay byte-identical across the two repositories.
